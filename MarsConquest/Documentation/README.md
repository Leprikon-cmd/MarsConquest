рабочий вопрос.

## Архив идей

Архив не задаёт текущую работу и не должен открываться перед обычной задачей. Он сохраняет
материал, к которому можно вернуться только при отдельном решении начать соответствующий этап.

- [Личный журнал — исходная концепция](Archive/PersonalJournal/concept-2026-09.md)
- [Карьерные идеи: карта CEO, статусы и Career XP](Archive/Career/)
- [Завершённые этапы и история сборок](Archive/Completed/)

## Простое правило

Если документ противоречит `PROJECT_CONTEXT.md`, верным считается `PROJECT_CONTEXT.md`.
Если идея есть только в архиве, она отложена и не является задачей разработки.
