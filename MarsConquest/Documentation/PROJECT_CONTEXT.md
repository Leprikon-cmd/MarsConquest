## Назначение

Mars LogBook — локальный iPhone-журнал партий в «Покорение Марса». Он помогает собрать команду,
зафиксировать результаты экспедиции, сохранить детали и наблюдать личную статистику владельца.

Подробная продуктовая граница: [PRODUCT_CONCEPT.md](PRODUCT_CONCEPT.md).
Тон и правила интерфейса: [APP_PERSONALITY.md](APP_PERSONALITY.md).

## Состояние на сегодня

**P0–P4 завершены.** Базовый iPhone-журнал готов: партия, результаты, история, статистика,
локализация и резервный архив работают штатно. Подробности выполненных этапов и история сборок
находятся в [Archive/Completed](Archive/Completed/): их не нужно читать для обычной работы.

**P5 не начат.** Следующий функциональный этап запускается только отдельным решением владельца
проекта. Карьера, титулы, рекорды и карта CEO остаются в P8.

## Ключевые решения

| Решение | Правило |
|---|---|
| Устройство | Новая работа ориентирована только на iPhone. |
| Хранилище | Core Data, активная модель `GameDataModel 11`; старые модели не переписываются. |
| Идентичность | `SavedPlayer.id` — стабильный UUID человека; имя не используется для автоматической привязки. |
| Сохранение | Новые партии, резервное восстановление и исторический импорт пишутся в отдельном контексте Core Data. |
| Архив | Повторный UUID не создаёт копию и не перезаписывает текущую запись. |
| Настройки | Язык, звук и тестовый режим остаются на конкретном iPhone; коллекция принадлежит профилю. |
| Локализация | Новые записи сохраняют постоянные игровые ключи, а текст выбирается по активному языку. |
| Интерфейс | Нижняя навигация учитывается единым `JournalNavigationLayout.contentBottomClearance`. |
| Комментарии | Каждый Swift-файл имеет русскую шапку: «Зачем», «Кто», «Что можно менять руками». |

## Очередь работы

### P5 — компаньон партии, не начат

Перед началом требуется отдельное решение о составе первого шага. В черновой очереди:

1. драфт и его сохранение вместе с партией;
2. первый игрок, порядок хода, передача телефона и пас;
3. мягкий таймер поколений;
4. шахматный контроль времени и домашние правила;
5. отображение этих параметров в истории и статистике.

### P6 — закрытые группы, будущее

Закрытые группы друзей, общие партии и подтверждение результатов участниками.

### P7 — клубы и турниры, будущее

Роль организатора, турнирные правила, отдельная подтверждённая статистика и журнал исправлений.

### P8 — карьера, отложено

Карьерный прогресс, титулы, рекорды, события и карта CEO не развиваются сейчас. Исходные идеи
сохранены в [Archive/Career](Archive/Career/).

## Правило обновления документации

После значимого изменения обновляются только документы, которых оно касается. Не добавлять
концепцию в `PROJECT_CONTEXT`, если это лишь будущая идея: либо внести её в очередь одной строкой,
либо сохранить в архиве до отдельного решения.
