# Mars LogBook — проверки

Этот документ не заменяет запуск приложения. Он помогает быстро выбрать минимальную проверку
после конкретного изменения.

## Наборы проверок

| Изменение | Запустить |
|---|---|
| Очки, награды, достижения, ничьи | `ScoringRulesTests` |
| Добавление и редактирование участника | `PlayerValidationTests` |
| Старые названия, игровые ключи, импорт | `JournalCompatibilityTests` |
| Core Data, сохранение, миграция | `MarsConquestTests` |
| Главный маршрут на iPhone | UI smoke-набор |

## Что проверяют тесты

- правила подсчёта и порядок тай-брейка;
- уникальность участников, корпораций и прологов;
- распознавание исторической «Элады» и приоритет постоянных игровых ключей;
- полную запись партии, изолированное сохранение, отказ без частичных данных и повторную попытку;
- миграцию минимальных SQLite-баз моделей 5–10 к активной модели 11;
- маршрут «Высадка! → карточка владельца → команда» и внесение экспедиции в журнал.

UI-тесты используют отдельную базу в памяти. Они не меняют реальную историю на устройстве.

## Перед TestFlight

1. Запустить все модульные тесты.
2. Запустить UI smoke-набор, если рабочая среда Xcode доступна.
3. На iPhone пройти: журнал → новая экспедиция → команда → результаты → внесение → подробности.
4. Повторить ключевые действия на русском и английском.
5. Создать резервный архив, повторно принять его и убедиться, что копии партий не появились.

## Резервный архив

Обычная безопасная проверка: создать архив в «Файлах», сразу принять тот же файл и убедиться,
что приложение сообщает о уже отражённых сведениях. Полная проверка на отдельном чистом iPhone
полезна перед крупным выпуском: сравнить историю, профиль, коллекцию, аватар и селфи, затем
повторно принять файл без появления дублей.

## Ограничения

Тесты не заменяют открытие реальной старой базы и перенос архива на другое чистое устройство.
Это редкие пострелизные проверки, которые выполняются при появлении подходящего устройства или
исторической базы.
