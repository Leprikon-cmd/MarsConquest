# Проверка интерфейса: iPad и Mac

## Автоматически

UI-тесты `MarsConquestUITests` запускаются на `iPad mini (A17 Pro)` с отдельным
тестовым профилем. Они проходят маршрут «Бортовой журнал -> Новая экспедиция ->
Команда экспедиции» и проверяют, что нижняя навигация и кнопка «Начать партию»
остаются внутри окна и доступны для нажатия.

Тестовый профиль создаётся только при специальном аргументе запуска UI-теста и
не влияет на данные пользователя при обычном запуске приложения.

Desktop-вариант собирается отдельной проверкой Xcode для `My Mac (Designed for iPad and iPhone)`. Его интерфейс нужно оценивать вручную по сценарию ниже: режим совместимости iPad на Mac не даёт такого же надёжного автоматического UI-контура, как симулятор.

## Проверка на iPad mini

1. Открыть бортовой журнал: бейдж, действия и нижняя навигация видны целиком.
2. Нажать «Новая экспедиция»: круг поля и «Высадка!» не обрезаются.
3. Открыть команду экспедиции: кнопка «Добавить игрока» находится ниже заголовка; нижние кнопки видны над системной зоной.
4. Добавить 1, затем 3 игроков: карточки не выходят за границы и прокручиваются над нижними действиями.
5. Открыть настройки и вернуться: выбранная вкладка остаётся на месте.

## Проверка на Mac

1. Открыть приложение в обычном окне: в центре виден бортовой журнал, а не только фоновое изображение.
2. Растянуть окно: рабочая колонка остаётся читаемой и не растягивается на всю ширину.
3. Переключить «Бортовой журнал», «Регалии» (если есть) и «Настройки»: навигация остаётся внизу окна.
4. Открыть «Новую экспедицию» и «Команду экспедиции»: действия доступны, элементы не накладываются на заголовок или нижнюю системную зону.
5. Уменьшить окно до компактной ширины: содержимое прокручивается, кнопки не исчезают.

## Ожидаемый результат

Фоновая иллюстрация всегда занимает окно, а рабочие элементы располагаются в отдельной центральной колонке. На широких экранах интерфейс не должен превращаться в растянутый телефонный экран и не должен исчезать с экрана.
